# res/

`openkrisp.png` がアイコンの元画像で、`openkrisp.ico` はそれを
16/20/24/32/40/48/64/128/256 の 9 サイズへ縮小して 1 つにまとめたものです。

元画像を差し替えたら、次のコマンドで `.ico` を作り直してください。

```powershell
.\res\make-icon.ps1
```

## ハマりどころ

**各サイズは PNG ではなく従来型の DIB で格納しています。**
PNG 圧縮の ICO は Windows 自体は読めますが、リソースコンパイラ（`rc.exe`）が
`RC2176: old DIB in openkrisp.ico` で撥ねるため exe に埋め込めません。

**`.rc` は `.ico` を参照しているだけなので、CMake は依存として拾いません。**
`CMakeLists.txt` で `OBJECT_DEPENDS` を指定して、アイコンを差し替えたときに
`.rc` が確実に再コンパイルされるようにしてあります。これが無いと、`.ico` を
差し替えても `.rc` の日付が変わらず、古いアイコンが exe に残ります。

**`make-icon.ps1` は UTF-8 BOM 付きで保存してください。**
PowerShell 5.1 は BOM の無いファイルを ANSI（日本語環境では CP932）として読むため、
日本語コメントの直後の改行が 2 バイト文字の一部として食われ、**次の行がコメントに
飲み込まれます**。このスクリプトは C# を埋め込んでいるので、そうなると
「一部の書き込みだけが消えた壊れた ICO」が黙って出来上がります。
`build.ps1` も同じ理由で BOM 付きです。
